# Changelog — RTS-MK1

All notable changes to **RTS-MK1** (`https://rts-mk1.orbital8.cloud`) follow strict non-reusable `v1.x.y` versioning.

## [v1.3.1] — 2026-10-28

### Fixed
- **Root-Cause Elimination of Periodic Frame Drops & Severe Gameplay Stutters (`src/engine/simulation.ts`, `src/engine/fog/fog-of-war.ts`, `src/store/game-store.ts`, `src/components/hud/classic-sidebar-hud.tsx`, `src/components/hud/leonardo-icons.tsx`, `src/renderer/world-renderer.ts`, `src/renderer/minimap-renderer.ts`, `src/renderer/vfx-manager.ts`, `src/audio/mixer.ts`)**:
  - **Decoupled 20 Hz Simulation State from React HUD Re-Renders (`src/store/game-store.ts`, `src/components/hud/classic-sidebar-hud.tsx`, `src/components/hud/leonardo-icons.tsx`)**: Mutated `prevEntities`, `currEntities`, `oreGrid`, `terrainGrid`, `exploredByPlayer`, and `visibleByPlayer` in-place for the imperative 60 FPS `requestAnimationFrame` canvas loop (`useRtsGameStore.getState()`) and gated Zustand `set(...)` on `hudRevision` / `ownedBuildingsKey`. Wrapped `ClassicSidebarHud`, `FactionVectorEmblem`, and `ProductionItemVectorIcon` in `React.memo`, eliminating 20 Hz full-sidebar and 500-line SVG React DOM reconciliations on every simulation tick.
  - **$C^0$-Continuous Sub-Tick Entity Pose Interpolation (`src/shared/constants/index.ts`, `src/store/game-store.ts`)**: Added `interpolateEntityPose(prev, curr, alpha)` and captured each entity's exact rendered pose at the moment a new `SIM_DELTA` arrives as the new `prevEntities` baseline, eliminating visual forward jumps and micro-freezes caused by WebSocket jitter.
  - **Eliminated Synchronous `1536×1536` `OffscreenCanvas` Rebuilds on Ore Depletion (`src/renderer/world-renderer.ts`, `src/renderer/minimap-renderer.ts`)**: Normalized initial ore tiles (`terrainGrid[idx] === 3`) to base sand (`0`) in the static terrain cache and reused a single persistent `OffscreenCanvas` surface so depleting an ore tile during harvesting never triggers a synchronous 2,304-tile `OffscreenCanvas` allocation and redraw on the main thread.
  - **Horizontal Span Batching (Run-Length Encoding) for Fog of War & Cached Minimap Composite Layer (`src/renderer/world-renderer.ts`, `src/renderer/minimap-renderer.ts`)**: Replaced ~4,600 per-frame individual tile `ctx.fillRect` and `Set.has` calls in the two-layer Shroud/Fog of War overlay and Minimap with row-wise horizontal span batching and a cached composite minimap surface (`baseTerrain + orePresence + shroud`).
  - **Viewport Frustum Culling & Zero-Allocation Crater Rendering (`src/renderer/world-renderer.ts`, `src/renderer/vfx-manager.ts`)**: Added camera frustum culling across structures, units, craters, projectiles, explosions, and particles, replaced per-frame `ctx.createRadialGradient` allocations in `renderCraters` with layered radial fills, and hoisted `ctx.save()/restore()` outside the particle loop.
  - **Eliminated Harvester Ping-Pong, Refinery Dock Deadlock & Combat A* Pathfinding Storms (`src/engine/simulation.ts`, `src/engine/fog/fog-of-war.ts`)**: Fixed the 3-tick Harvester state-machine loop at ore patch edges (`dist <= 1.55` to `targetOreTile`), replaced the Refinery center-distance check (`dist <= 2.4`, which missed 8 of 14 perimeter dock tiles and triggered every-tick A* pathfinding) with a footprint-perimeter check (`distToFootprint <= 1.55`), added per-tick A* repath budgets (`maxDynamicRepathsPerTick = 4`, `maxChaseRepathsPerTick = 4`) and `waitTicks` cooldowns, restricted 30-tick AI wave dispatches to idle units, and added spatial sight-signature caching to `FogOfWarManager`.
  - **WebAudio Graph Node Cleanup (`src/audio/mixer.ts`)**: Disconnected temporary `StereoPannerNode` and `GainNode` instances after sound completion so combat audio nodes never accumulate in the `AudioContext` graph.

## [v1.3.0] — 2026-10-28

### Added
- **Responsive Mobile Landscape Mode & Multi-Touch Tactical Controls (`src/shared/constants/index.ts`, `src/app/layout.tsx`, `src/app/game/[lobbyId]/page.tsx`, `src/components/hud/classic-sidebar-hud.tsx`, `src/components/lobby/portal-command-center.tsx`)**:
  - Added pure deterministic touch action resolver (`resolveTouchTapAction`, `TOUCH_INTERACTION_MODES`: `AUTO`, `PAN`, `SELECT`, `COMMAND`) enabling 1-tap unit selection, 1-tap ground move (`COMMAND_MOVE`), 1-tap enemy targeting (`COMMAND_ATTACK`), 1-tap building placement (`COMMAND_PLACE_BUILDING`), and structure selling on mobile touchscreens.
  - Added 1-finger map drag panning (in `AUTO`/`PAN` modes), 1-finger touch box-selection (in `SELECT` mode), 2-finger touch drag & pinch-to-zoom, an on-screen directional camera pad + "Base" & "Sélect. Armée" quick-action bar, and continuous touch-drag camera navigation on the Radar Minimap.
  - Redesigned the battlefield viewport (`h-dvh w-dvw touch-none`), lobby portal, and Classic C&C Sidebar HUD for **Mobile Landscape (`Paysage`)** with a collapsible sidebar drawer, toggleable compact Radar view, smooth vertical touch scrolling (`touch-pan-y`) for all 4 production queues (`Base`, `Déf.`, `Inf.`, `Blindés`), and a portrait-orientation advisory banner.

## [v1.2.0] — 2026-10-28

### Added
- **Leonardo High-Precision Multi-Layered Vector Art & SVG Assets (`src/renderer/generator/leonardo-vector-art.ts`, `src/components/hud/leonardo-icons.tsx`, `src/renderer/generator/atlas-generator.ts`)**:
  - Upgraded the procedural `OffscreenCanvas` -> `ImageBitmap` pipeline to **2x internal resolution (`SPRITE_ATLAS_SCALE = 2`, `64x64` per tile)** for razor-sharp visuals up to `2.0x` tactical zoom.
  - Added 4-layer technical vector illustrations for all 11 structures, 9 units (across 16 orientations + independent rotating turrets), 4 terrain types, and a 12-frame procedural explosion sprite strip.
  - Added multi-layered `<svg>` faction emblems (`FactionVectorEmblem`) and unit/building technical schematic cards (`ProductionItemVectorIcon`) across the Portal and Classic C&C Sidebar HUD (`0` inline `style` attributes).
- **Battlefield Game Juice Engine — Explosions, Shockwaves, Craters, Damage Smoke & Camera Shake (`src/renderer/vfx-manager.ts`, `src/renderer/camera.ts`, `src/shared/schemas/deltas.ts`, `src/audio/synthesizer.ts`)**:
  - Added `VisualEffectEventSchema` (`MUZZLE_FLASH`, `SHELL_IMPACT`, `ROCKET_EXPLOSION`, `LASER_BURN`, `UNIT_EXPLOSION`, `BUILDING_DEMOLITION`, `HARVEST_SPARKS`) in `TickDelta`.
  - Added quadratic trauma-based damped harmonic **Camera Shake** (`computeCameraShakeOffset`, `computeDistanceAttenuatedShakeTrauma`) on `TacticalCamera` with distance attenuation.
  - Added `BattlefieldVfxManager` rendering 60+ FPS traveling projectiles (smoke-trailing rockets, glowing thermal lasers, artillery shells), multi-stage explosions, shockwave rings, persistent scorched craters, harvesting crystal sparks, and rising damage smoke/embers on structures and vehicles below 55% HP.
  - Enhanced `EXPLOSION_LARGE`, `EXPLOSION_SMALL`, and `CANNON_FIRE` in `src/audio/synthesizer.ts` with deep sub-bass impact oscillators.

### Fixed
- **Root-Cause Elimination of Engine & Frame-Pacing Stutter (`src/engine/simulation.ts`, `src/store/game-store.ts`, `src/app/game/[lobbyId]/page.tsx`, `src/renderer/world-renderer.ts`, `src/renderer/minimap-renderer.ts`, `src/audio/synthesizer.ts`)**:
  - **Sub-Tile Waypoint Residual Traversal (`src/engine/simulation.ts`)**: Fixed the root-cause movement slowdown in `stepUnitMovement()` where units reaching a waypoint with `dist <= step` discarded the remainder of their movement step (`step - dist`), causing an ~85% speed drop every time a unit crossed a tile boundary (~3 times/sec). Units now consume their full `speedTilesPerTick` budget seamlessly across consecutive path segments within the same tick.
  - **Zero-React-Re-render 60 FPS Loop (`src/app/game/[lobbyId]/page.tsx`, `src/store/game-store.ts`)**: Replaced un-selected `useRtsGameStore()` hooks with atomic Zustand selectors and mutated `pendingAcousticEvents` / `pendingVisualEffects` in-place via `.splice()` instead of calling `set()` inside `requestAnimationFrame`, eliminating 20 Hz–60 Hz full-page React DOM reconciliations during combat.
  - **Zero Layout Thrashing (`src/app/game/[lobbyId]/page.tsx`)**: Replaced per-frame `canvas.getBoundingClientRect()` inside `requestAnimationFrame` with a container `ResizeObserver`.
  - **OffscreenCanvas Terrain & Minimap Caching + Shortest-Arc Angle Interpolation (`src/renderer/world-renderer.ts`, `src/renderer/minimap-renderer.ts`)**: Cached the static 48x48 battlefield terrain and minimap base layers on offscreen surfaces (eliminating >3,500 redundant draw/fill calls per frame) and added `interpolateAngleIndex16` + adaptive tick duration smoothing.
  - **AudioBuffer `WeakMap` Cache (`src/audio/synthesizer.ts`)**: Cached Hann-windowed white/pink noise `AudioBuffer`s per `AudioContext` to eliminate synchronous main-thread `Float32Array` allocations and `Math.sin()` loops during heavy firefights.

## [v1.1.0] — 2026-10-28

### Added
- **Smooth Edge-of-Screen Camera Auto-Scroll (`src/shared/constants/index.ts`, `src/app/game/[lobbyId]/page.tsx`)**: Added progressive quadratic edge-of-screen camera panning (`computeEdgeScrollVelocity`, `EDGE_SCROLL_MARGIN_PX = 36`, `EDGE_SCROLL_MAX_SPEED_PX = 3.2`) when the cursor enters a 36px viewport border zone, ensuring gentle, non-violent camera movement without interfering with box-selection drags.
- **Tactical Camera Zoom Selector (`1`, `1.25`, `1.5`, `1.75`, `2`)**: Added `ZOOM_LEVELS` (`[1, 1.25, 1.5, 1.75, 2]`) in `src/shared/constants/index.ts`, center-preserving `setZoom()` and `cycleZoom()` in `src/renderer/camera.ts`, and interactive Zoom cycle + direct level selector buttons (`1`, `1.25`, `1.5`, `1.75`, `2`) in both the top tactical viewport bar (`src/app/game/[lobbyId]/page.tsx`) and the classic sidebar HUD (`src/components/hud/classic-sidebar-hud.tsx`).
- **Ghost Building Sprite & Placement Validation Preview**: Rendered the faction-colored building sprite preview inside `renderTacticalWorld` (`src/renderer/world-renderer.ts`) and synchronized client-side placement validation (`canPlaceBuildingOnGrid`) with server-side footprint, unit-occupancy, and base build radius rules (`BASE_BUILD_RADIUS_TILES = 16`).

### Fixed
- **Root-Cause Building Deployment Delta Synchronization & Friendly Unit Relocation (`src/engine/simulation.ts`)**: Fixed the tick lifecycle in `RtsSimulation.stepTick()` where `createdThisTick`, `destroyedThisTick`, `acousticEventsThisTick`, and `ent.dirty` were cleared at the *beginning* of `stepTick()` instead of at the *end* after serializing `TickDelta`. WebSocket commands (`COMMAND_PLACE_BUILDING`, `COMMAND_SELL_BUILDING`) executed between 20 Hz ticks now reliably include the deployed or sold building in the next `SIM_DELTA` packet (`delta.created` / `delta.destroyedIds`). Friendly mobile units standing on a new building footprint are also automatically relocated to the nearest free perimeter tile instead of silently blocking deployment.

## [v1.0.0] — 2026-10-28

### Added
- **Agent 01 (`src/shared/`)**: Strict Zod validation schemas (`commands`, `deltas`, `lobby`, `profile`, `env`), inferred TypeScript types (`strict: true`, zero `any`), and full Command & Conquer / Dune 2000 unit, structure, tech-tree, and faction balance constants (`GDI`, `NOD`, `ORDOS`).
- **Agent 02 (`src/engine/`)**: Deterministic 20 Hz ECS simulation engine (`simulation.ts`), binary-heap A* pathfinding with deterministic spatial tile reservation (`pathfinding/`), two-layer Shroud & Fog of War (`fog/`), Harvester-Refinery-Silo economy loop, power deficit penalties, 4 parallel production queues (`BUILDING`, `DEFENSE`, `INFANTRY`, `VEHICLE`), skirmish AI controller, and compact Zod-validated Delta + Snapshot generation.
- **Agent 03 (`src/server/`, `src/app/api/`)**: Single Active Match Mutex (`lobby-manager.ts`) enforcing at most 1 active (`STARTING` / `IN_PROGRESS`) match with ordered FIFO `QUEUED` lobby rank broadcasting and a 10s/60s `ping/pong` Watchdog automatic lock release; authoritative WebSocket server (`ws-server.ts`) on `/ws`; persistent SQLite WAL commander profile & match history database (`src/server/db/`).
- **Agent 04 (`src/app/`, `src/components/`, `src/store/`)**: Portal, live server mutex badge & lobby browser, waiting/queue room, Classic Westwood C&C / Dune 2000 sidebar HUD (`src/components/hud/`) with radar canvas slot, discretized Tailwind power & progress bars, 100% Tailwind CSS with zero inline `style` attributes, and Zustand store bridge (`src/store/game-store.ts`).
- **Agent 05 (`src/renderer/`)**: Asynchronous batched `OffscreenCanvas` -> `ImageBitmap` procedural vector/bitmap sprite atlas generator (`generator/atlas-generator.ts`) across 16 rotation angles and faction team color masks with explicit GPU `.close()` cleanup; orthogonal camera (`camera.ts`); 60+ FPS linear-interpolated tactical world canvas renderer (`world-renderer.ts`); real-time radar minimap renderer (`minimap-renderer.ts`).
- **Agent 06 (`src/audio/`)**: Procedural Web Audio API sound synthesizer (`synthesizer.ts`), 4-bus mixer (`mixer.ts`) with strict 4-instance / 80ms polyphony limiter and automatic EVA ducking, and camera-relative stereo panning & distance attenuation (`spatial.ts`).
- **Agent 07 (`Dockerfile.web`, `Dockerfile.ws`, `docker-compose.yml`, `infra/`)**: Multi-container Docker Compose infrastructure (`reverse-proxy`, `web`, `ws-server`, `db`) tagged `v1.0.0`, non-root user execution, CPU/RAM limits, Zod environment validation, and HTTPS + `/ws` deployment on `https://rts-mk1.orbital8.cloud`.
